# 方块末日 ZOMBIE CRISIS

AI 制作的非商业 Minecraft 二创网页游戏（参考童年网页游戏《僵尸危机》）。

## 怎么玩

直接打开 index.html 所在地址即可（GitHub Pages）。
手机端：横屏 + 左下摇杆移动，右下大招攻击，自动索敌最近敌人。

## 目录

- index.html / assets/  —— 构建好的网页（Pages 直接跑这个）
- src/                 —— 全部源码
- package.json 等       —— 本地开发用

## 本地开发

npm install
npm run dev
npm run build   # 产物输出到 docs/
